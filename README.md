# 🎓 Campus Life: Financial Literacy & Simulation Game

An interactive, web-based simulation game designed to teach students practical financial literacy, decision-making, and resource management through daily campus scenarios.

---

## 🌟 Key Features

### 🔹 Feature 1: Dynamic Campus Decision Engine
* **Interactive Scenarios:** Real-world daily campus choices involving academics, social life, and expenses.
* **Balanced Metrics:** Tracks and balances Health, GPA, and Wallet with every choice made.

### 🔹 Feature 2: Smart Financial Tracker & Budget Analyzer
* **Expense & Savings Logic:** Real-time calculation of daily spending and budget limits.
* **Instant Feedback Loop:** Visual alerts when expenses exceed sustainable thresholds, helping players learn smart spending habits.

---

## 🛠️ Built With

* **HTML5:** Semantic game structure and responsive layout.
* **CSS3:** Modern UI styling, progress meters, and dynamic cards.
* **JavaScript (Vanilla ES6):** State management, decision logic, and score calculations.

---

## 💡 About the Project
Built as part of a mission to gamify personal finance and make core financial education accessible, engaging, and practical for youth.
